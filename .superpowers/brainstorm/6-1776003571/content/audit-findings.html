Request Detail — UX Audit Findings

Agent/Admin perspective · 8 issues identified · prioritised by impact

🔴 Critical — Blocks agent productivity
Critical

1. Workflow actions use browser prompt() dialogs

All IT and Finance workflow actions (Submit for Approval, Start Procurement, Fulfilment) use native browser prompt() — no validation UX, no user picker, breaks the visual language entirely. Caused today's UUID crash.

→ Replace with inline modal forms with proper inputs and validation
Critical

2. "Next action" is buried — no clear call-to-action

The ActionBanner tells agents something needs to be done, but the actual action buttons (Approve, Assign, Submit) are scattered across different sections far below, with no visual hierarchy pointing the agent to "do this next".

→ Consolidate next-action CTA into a sticky Agent Action Panel on the right sidebar
🟡 High — Friction in daily use
High

3. Right sidebar is read-only metadata, wastes prime real estate

The right column (Reference Number, Status, Priority, Service Desk, Requester) shows static info an agent already knows. Agents need to act, not read — but the action zone is on the left in a sea of content.

→ Move key actions to sidebar; metadata collapses to secondary view
High

4. Status badge and stepper are disconnected

The stepper at the top shows progress but the "Status" badge in the sidebar repeats it as a raw enum string (e.g. "SUBMITTED"). Agents see two conflicting representations of the same thing with different formatting.

→ Remove sidebar status badge; stepper is the single source of truth for progress
High

5. IT/Finance workflow sections show even when irrelevant

The "IT Workflow" and "Finance Workflow" section headers always render for those service desks, even when there are no actions to take (e.g. after resolution). Creates visual noise and confusion about what's pending.

→ Collapse workflow sections when no pending action exists; show only active step
🔵 Medium — Polish and clarity
Medium

6. "Assign to Agent" dropdown is not surfaced prominently

The AssignToDropdown component exists but blends into the sidebar. New tickets showing "Unassigned" with an orange warning triangle are the highest priority — but assignment feels like a secondary task visually.

→ Elevate assign action to top of sidebar with a distinct "Claim / Reassign" button state
Medium

7. Activity log filter tabs (All / Comments / Activity / Internal) are low contrast

The tab labels are small and the active state styling is subtle. Agents use Internal notes frequently to coordinate — but the tab is visually identical to unselected tabs at a glance.

→ Increase tab contrast; add unread count badges on Comments and Internal tabs
Medium

8. Comment box lacks quick-reply affordances

The comment input is a plain textarea with no indication of its power — no character count, no draft indicator, no template shortcuts for common agent replies ("Resolving this now", "Escalating to…").

→ Add agent reply templates and an Internal Note toggle that's more visually distinct
