WF-01 Lead Management Workflow

Objective: Capture every prospect the same day first contact is made, deduplicate, assign within 4 hours, qualify or disqualify within 5 business days, and convert qualified leads to opportunities without delay.
End-to-End Flow Diagram
flowchart TD A([📋 Lead Captured]) --> B{Duplicate\nCheck} B -->|Match ≥ 85%| C[Review Existing\nRecord] C --> D{Same Person?} D -->|Yes| E[Update Existing\nRecord] D -->|No| F[Save as New\nwith Note] B -->|No Match| G[Save New Lead] F --> G G --> H[Assign to Rep\nwithin 4 hours] H --> I{Assigned\nwithin 4h?} I -->|No| J[🔔 Manager Alert] J --> H I -->|Yes| K[Rep Logs First\nActivity within 24h] K --> L{Activity\nLogged?} L -->|No| M[🔔 Manager Alert\n+ Rep Reminder] M --> K L -->|Yes| N{Lead\nQualified?} N -->|No — Cold| O[Mark Cold /\nDisqualified] N -->|Needs more info| P[Schedule\nFollow-Up] P --> N N -->|Yes — Hot/Warm| Q[Convert to\nOpportunity] Q --> R([🚀 Pipeline:\nProspecting Stage])
Swimlane Breakdown
Role
Responsibilities in this Workflow
Sales Rep
Search before creating → Fill mandatory fields → Log first activity within 24h → Qualify lead → Convert to opportunity or mark as disqualified
Sales Manager
Review unassigned leads twice daily → Assign leads within 4 hours → Monitor rep activity compliance → Review AI lead score weekly
CRM System
Auto-duplicate detection at save → Timestamp creation → Notify rep on assignment → Alert manager at 4h unassigned → Alert manager at 48h no activity → AI scoring (0–100) daily refresh

Assigned within 4h? → If No: manager alert fires

WF-02 Opportunity Pipeline Workflow

Objective: Move qualified prospects through the 5-stage sales pipeline to a deal decision, maintaining stage accuracy, activity continuity, and revenue forecast integrity at every step.

WF-06 Duplicate Detection & Merge Workflow

Objective: Detect and resolve duplicate CRM records before they fragment the customer view. The system automatically flags potential duplicates; users review and decide to merge or dismiss.
End-to-End Flow Diagram
flowchart TD A([📝 Record Created or Updated]) --> B[Matching Engine\nName + IC + Phone + Email] B --> C{Potential\nMatch Found?} C -->|No| D([✅ Record Stored\nNo duplicate flag]) C -->|Yes| E[CrmDuplicateMatch Created\nwith confidence score] E --> F[Alert appears in\nDuplicate Detection page] F --> G{User Decision} G -->|Merge| H[Select Primary Record\nResolve field conflicts] H --> I[Merged Record\nSecondary soft-deleted] I --> J([✅ Single unified record]) G -->|Dismiss| K[Mark 'Not a duplicate'\nReason required] K --> L([✅ Dismissal logged\nBoth records retained])
Decision Points
Confidence ≥ 95%? → Strong match, merge recommended

Same IC/Passport? → Exact match, merge required

Merge or Dismiss? → Unified record vs. keep separate with reason
Automation Triggers
Matching engine runs on every record create/update
IC/Passport exact match → auto-flag at 100% confidence
Name + phone proximity match → flag at 80%+
Duplicate Rate Merge Resolution Time

WF-07 Data Import Workflow

Objective: Bulk-import CRM records from external sources using a validated CSV template, ensuring data quality and duplicate prevention at every step.
End-to-End Flow Diagram
flowchart TD A([📥 Import Request]) --> B[Download CSV Template\nfor target entity] B --> C[Populate data\npreserving header row] C --> D[Upload CSV file\nMax 10,000 rows] D --> E[System Analyzes Headers\nMap columns to CRM fields] E --> F{All columns\nmapped?} F -->|No| G[Adjust field mapping\nmanually] G --> E F -->|Yes| H[Click Validate\nDry-run check] H --> I{Validation\npassed?} I -->|Errors| J[Review error report\nFix data in CSV] J --> D I -->|Pass| K[Click Execute Import] K --> L[Import Results\nCreated / Updated / Skipped / Errors] L --> M([✅ Import logged\nin audit trail])
Decision Points
Headers match template? → If No: mapping step required

Validation pass? → If No: fix CSV errors before import

Duplicates detected? → Flagged for review, not auto-created
Automation Triggers
Auto-detect column types from CSV headers
Mandatory field validation on every row
Duplicate check (IC + name) on every candidate row
Error rows skipped — partial import proceeds

WF-08 Email Sync & Activity Auto-Log Workflow

Objective: Connect email (Google/Outlook) to CRM so that customer communications are automatically captured as activities. Reduces manual logging burden and ensures no customer interaction is missed.
End-to-End Flow Diagram
flowchart TD A([🔗 User Connects Email]) --> B[CRM > Integrations\nClick Connect Google/Outlook] B --> C[OAuth Consent Screen\nGrant CRM read access] C --> D{Consent\ngranted?} D -->|No| E([❌ Sync not enabled\nManual logging only]) D -->|Yes| F[Configure sync preferences\nDirection / Folders / Frequency] F --> G[Sync Engine activated\nper configured schedule] G --> H[New email received\nfor CRM-linked contact] H --> I{Contact\nmatches?} I -->|Yes| J[Auto-create Email activity\nlinked to Contact + Account] J --> K[Email visible in\nEmail Thread Viewer] I -->|No| L([⏭️ Email skipped\nNot CRM-linked]) K --> M([📊 Activity logged\nwithin compliance SLA])
Decision Points
OAuth consent granted? → No sync without user authorisation

Sender/recipient matches CRM contact? → Only linked contacts' emails are captured

Calender sync enabled? → Calendar events also synced if configured
Automation Triggers
Sync engine runs per configured frequency (15 min default)
Auto-create Email activity for matched contacts
Privacy boundary: only CRM-linked contacts' emails synced
Sync Coverage Activity Logging SLA
